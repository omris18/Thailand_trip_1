# תיקון העלאת תמונות

## 1. GitHub
החליפו רק את `index.html` בקובץ המצורף.

בגרסה הזו:
- כפתור תמונת הבדיקה הוסר מהמסך.
- לחיצה על "סיימנו את המשימה" מעלה רק את התמונות שבחרתם.
- אם לא נבחרה תמונה, מוצגת הודעה לבחור תמונה ולא נוצרת תמונת בדיקה.

## 2. Firebase Storage Rules
Firebase Console → Storage → Rules

מחקו את הכללים הקיימים, הדביקו את כל תוכן `storage.rules` ולחצו Publish.

התיקון מאפשר למשפחה לקרוא את התמונה שהיא עצמה העלתה, כדי שהאתר יוכל לקבל את כתובת התמונה ולהציג אותה. מנהל יכול לקרוא את כל התמונות.

## 3. בדיקה
1. פתחו את האתר עם `?f=sadeh`.
2. פתחו את יום 1.
3. לחצו באזור "צלמו עכשיו או בחרו מהגלריה".
4. בחרו תמונה אמיתית וודאו שהיא מופיעה בתצוגה המקדימה.
5. לחצו "סיימנו את המשימה".
6. בדקו ב-Firebase Storage:
   `trip-photos/sadeh/2026-07-26/`
7. פתחו את דף המנהל ובחרו 26.07.2026.
